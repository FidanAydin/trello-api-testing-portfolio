# trello-api-testing-portfolio

I created this project as a part of my QA tester portfolio to showcase my API testing skills. API testing is implemented to check if the backend is working properly. The advantage of API testing is that, we can get faster results without needing to click buttons on UI.
In API testing we need to verify that HTTP requests are done properly and we are getting the correct status codes.
This particular API testing is done using Postman to test Trello REST APIs. The tests are built on Trello API documentation
